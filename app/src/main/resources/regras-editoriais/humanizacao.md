# Diretrizes de humanização do Revora

O objetivo não é determinar se um texto foi escrito por inteligência
artificial.

O objetivo é identificar trechos com características de escrita
mecanizada, artificial, repetitiva ou editorialmente pobre.

A análise deve ser conservadora.

Devem ser observados:

- repetição de uma mesma ideia sem avanço argumentativo;
- pensamento circular;
- enumerações artificiais;
- uso recorrente de grupos de três qualificadores ou conceitos;
- clichês e construções genéricas;
- excesso de expressões como "é importante destacar",
  "é fundamental compreender", "nesse sentido" e similares;
- transições excessivamente mecânicas entre parágrafos;
- perguntas artificiais dirigidas ao leitor;
- períodos longos sem necessidade;
- repetição de palavras ou construções;
- referências vagas como "estudos mostram" quando não há identificação;
- afirmações genéricas apresentadas como conclusão;
- excesso de adjetivação;
- linguagem aparentemente sofisticada sem ganho de significado;
- ritmo textual excessivamente uniforme.

Nunca afirmar que o texto foi produzido por IA.

Usar expressões como:
"possível artificialidade textual",
"construção mecanizada",
"trecho com baixa naturalidade textual"
ou equivalente.

Não reescrever o documento inteiro.

Para cada ocorrência, fornecer:
- localização;
- evidência;
- motivo;
- sugestão de melhoria.
