# Diretrizes de normatização do Revora

A análise de ABNT deve observar principalmente:

- apresentação das citações;
- sistema autor-data;
- consistência entre autor e ano;
- citações diretas;
- indicação de página quando necessária;
- referências bibliográficas;
- uniformidade da lista de referências;
- consistência entre citações presentes no texto e referências finais.

A análise deve apontar possíveis divergências.

Não inventar autores, datas, páginas, títulos ou referências ausentes.

Quando não houver informação suficiente para confirmar uma inadequação,
indicar que o trecho deve ser verificado, em vez de afirmar que está errado.

Para cada ocorrência, fornecer:
- localização;
- evidência;
- motivo;
- sugestão de adequação.
