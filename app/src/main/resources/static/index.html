Tipos de revisão
Ortografia — possíveis palavras grafadas incorretamente.
Gramática e contexto — possíveis problemas de concordância, construção ou uso contextual.
Formatação — desvios em relação ao padrão definido pelo template.
Estrutura — elementos esperados que não foram encontrados no documento.
Após a revisão

As marcações são mantidas no arquivo para facilitar a conferência das sugestões.

Depois de realizar as correções, selecione o conteúdo do documento no Word e, em Cor do Realce de Texto, escolha Sem Cor.

O Revora aponta possíveis problemas. A decisão final de alteração permanece com o revisor.
